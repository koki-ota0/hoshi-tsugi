# Data safety 申告案

Play Console の「データ セーフティ」は **アプリに入っている SDK と一致**させる。
広告を入れる前と後で二段。提出前に APK を再確認する。

## A. 広告なし（閉鎖テスト初日）

| 質問 | 回答 |
| --- | --- |
| ユーザーデータを収集・共有するか | いいえ（端末内の進行のみ。Google の定義では「収集」は開発者のサーバへ送ること） |
| 暗号化して転送するか | 該当なし |
| 削除を依頼できるか | 該当なし（アンインストールで消える） |
| アカウント作成 | なし |
| お子様 | Families 対象外 |
| 広告 | なし（このビルド） |

端末内: SharedPreferences / localStorage 相当の進行データ。これは「収集」に含めない。

## B. AdMob 導入後

収集するデータ（AdMob の所定申告に合わせる）:

| 種別 | 収集 | 共有 | 目的 |
| --- | --- | --- | --- |
| 広告 ID | はい | はい（広告パートナー） | 広告 |
| 端末またはその他 ID | はい | はい | 広告・不正防止 |
| おおよその位置 | はい（IP から） | はい | 広告 |
| アプリ操作（広告表示） | はい | はい | 広告 |

- 必須ではない（コア機能は広告なしでも動く）
- 暗号化して転送: はい
- 削除リクエスト: Google アカウント / 広告設定に依存
- UMP 同意（EEA/UK）必須
- Data safety の「広告」トグルとリスティングの「広告あり」を両方オン

公式の AdMob データ開示をコピーし、こちらで勝手に減らさない。

## 権限（AndroidManifest に残さない）

カメラ、マイク、連絡先、SMS、精密位置。
INTERNET は AdMob と WebView で必要。AD_ID は広告導入時のみ。
