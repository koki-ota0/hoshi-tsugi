# ストア リスティング（日本語）

文字数は Play Console の上限。コピーして貼る。

## アプリ名（30）

```
星継
```

代替（世界観を足すとき）: `星継 — 夜の金継`

## 短い説明（80）

```
落ちた星を金で縫い、図に還す。夜の金継ぎ屋で星座を結ぶひとり遊び。
```

（36 文字。余白は意図的。）

案 B:

```
珠を放ち、欠けた星を縫う。金継ぎの星図パズル。
```

## 長い説明（4000）

```
落ちた星を、金で縫う。

星継は、夜の金継ぎ屋を舞台にしたひとり遊びです。
珠を放ち、欠けた星に当て、金の線で図を還していきます。
実在の星座と、門・五芒・巴・波などの幾何が交互に現れます。

・狙って放つだけ。教科書はありません
・縫い終わった図は図譜に残ります
・結星が伸びると等級が上がり、傷（威力）が変わります
・零等星から超新星まで、珠の数で等級が決まります
・縦持ちのまま、短い夜をひとつずつ

広告は図が終わったあと、または裂れたあとに出します（予定）。
遊ぶ途中の着弾中には出しません。
任意のリワードで珠を足すことがあります。

対象は一般向けです。子ども向け（Families）ではありません。
```

1. ホーム「落ちた星を金で縫い、図に還す」
2. 狙い（糸を引く）
3. 珠が飛ぶ
4. 星座が縫い上がる
5. クリア（等級と傷）
6. 図譜
7. 幾何の図（門や五芒）
8. 超新星の一閃
